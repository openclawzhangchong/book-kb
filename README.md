> **关键词**：书本知识库、文档知识库、AI智能体知识库、RAG切片、人设知识库、厚黑学、结构化整理

## 知识库标准结构（每本统一）

```
# 《XX》知识库
## 〇、总纲与使用说明      —— 起源/体系/智能体三步定位法
## 一、核心理论库          —— 原理逐条拆解，现代白话解读
## 二、招式/方法库         —— 主体：每条含【使用条件/操作步骤/话术模板/禁区】
## 三、场景范例库          —— 每例「普通人 vs 高手」完整对照 + 拆解
## 四、调用规则与输出风格  —— 场景路由表 + 人设语气 + 底线声明
```

**三条铁律**：
1. 每个小节固定三件套：`标题 / 关键词(4-8个) / 触发场景` —— 为 RAG 切片检索优化
2. 内容配比 80% 现代可执行方法 + 20% 原著点题；**历史案例必须降维成"模式卡"，只作一句话佐证，不许讲故事**——AI 学的是模式，不是故事
3. 底线声明内建最高优先级：只载合法自保与正当博弈，不教害人违法

## 整理流程（SOP）

完整方法论见 **[整理方法论-SOP.md](./整理方法论-SOP.md)**，已固化为可复用 Skill：**[skills/book-to-kb](./skills/book-to-kb/SKILL.md)**。

七步流水线：定位确认 → 结构设计 → 子Agent撰写 → 主Agent审核（8项清单）→ 修复复核 → 入库推送 → 交付终审。

## 使用方法

1. 下载对应书的 `.md` 文件
2. 装载进智能体知识库 / RAG 系统（按 `###` 三级标题切片，每片自带关键词与触发场景，召回即完整）
3. 智能体按第四章「路由表」自动定位，按四段式输出：诊断局势 → 给招 → 给话术 → 提示禁区
